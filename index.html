Projects

Bus Transit AI

TGSRTC GTFS-based transit engine

A zero-database Spring Boot backend that parses live TGSRTC transit feeds and turns them into a self-hosted, sub-second routing engine — no external database, just carefully built in-memory indexes.

  • Parses TGSRTC transit feeds across 5,000+ stops (~980k records) into custom HashMap indexes for O(1) sub-second lookups.
  • REST APIs for stop search, route planning, and nearest-stop detection, with AI-based query handling backed by a rule-based fallback.
  • Two-stage route planning: trip/stop-sequence traversal, Haversine geodistance logic, and Levenshtein fuzzy matching for stop search.
  • Containerized with Docker for scalable deployment; session-scoped API key handling (sessionStorage, automatic inactivity timeout) for security.
